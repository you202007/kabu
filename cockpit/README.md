# kabu — マクロ・フロー統合コックピット

日本株・円・マクロを **3つの時間軸レイヤー** で束ねて、
「今どのレジームか → どの傾きが有利か → いつ・どう執行するか → どのフローが近づいているか」
を週末に一望するための、単一HTMLの判断補助ツール。

> ⚠️ 本ツールは自分の観測を整理するための**判断補助**であり、投資助言・売買指示ではありません。
> 数値・傾き・リード期間はすべて目安です。

## レイヤー構成

| レイヤー | 時間軸 | 役割 | 中身 |
|---|---|---|---|
| 第1層 レジーム | 構造・週次 | スタンスを決める | 9KPI（円の避難挙動／USDJPY／米実質金利／Fed／JGB vs 3%／原油・地政学／AI・capex／資金ストレス／流動性）→ 4レジーム分類＋資産の傾き |
| 第2層 SQ戦術 | 需給・SQ週 | 執行モードを決める | SQ距離／D-1出来高／Max Pain／Pinning／CME夜間 → **レジーム×SQ** で執行モードが反転（ピン順張り／ブレイク追随／見送り） |
| 第3層 フロー警報 | カレンダー | 接近イベントを警戒 | 四半期末リバランス・配当再投資・指数リバランス（FTSE/Russell・MSCI・日経225）・SQ・決算/自社株買いブラックアウト等を自動計算し、接近アラート＋直近通過を表示 |

**設計の肝**：第1層のレジームが、第2層のSQ信号と第3層のイベントの「読み方」を上から書き換える。
同じ D-1 出来高スパイクでも、リスクオンなら「収束取り（ピン順張り）」、抑圧・危機なら「回避／ブレイク追随」に反転する。

## ファイル

- `weekly-regime-board.html` … 第1層のみの旧・週次盤（アーカイブ）

## 使い方

1. `index.html` をブラウザで開く（ローカルでも Pages でも可）。
2. 基点日を週末に合わせる。
3. 第1層でスタンス → 第2層でSQ週の執行モード → 第3層で接近フローを確認。
4. 「この週を記録」でスナップショットを保存（ブラウザのストレージに保持。レジーム遷移を週次で追える）。

## GitHub Pages でホストする場合

このリポジトリの GitHub Pages は `.github/workflows/pages.yml` の GitHub Actions 経由で配信されており、
`main` へのpush時に `cockpit/` 配下がそのまま `outputs/cockpit/` にコピーされてデプロイされます。
`https://youri202007.github.io/kabu/cockpit/` で `index.html` が配信されます。
